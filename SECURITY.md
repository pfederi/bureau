# Sicherheit

Bureau verwaltet Kundendaten, Rechnungen und Belege. Sicherheitslücken nehme ich ernst.

## Lücke melden

Bitte **nicht** als öffentliches Issue, sondern vertraulich über GitHub: im Repo unter **Security → Report a vulnerability** (auch beim Eröffnen eines Issues als Auswahl angeboten).

Hilfreich sind:

- betroffene Version (unten in der Seitenleiste)
- Beschreibung und Schritte zum Nachstellen
- mögliche Auswirkung (z. B. Zugriff ohne Login, fremde Kundendaten im Kundenportal)

Du bekommst in der Regel innert einer Woche eine Rückmeldung. Bitte veröffentliche Details erst, wenn eine korrigierte Version verfügbar ist.

## Unterstützte Versionen

Korrekturen gibt es für die jeweils neueste Version auf `main`. Halte deine Installation aktuell (siehe «Updates» in der Einrichtungsanleitung).
